Coherent optical links are increasingly considered for high-capacity intra-datacenter communication, but their receiver \ac{DSP} requires efficient carrier recovery to compensate residual carrier frequency offset and laser phase noise. Conventional blind phase search provides robust phase estimation for square-QAM constellations, but its hardware cost grows with the number of tested phase candidates. This thesis presents a fixed-point \ac{FPGA} implementation of a low-complexity carrier-recovery backend for baudrate-sampled \ac{16QAM} coherent links. The architecture combines serialised binary phase search, which estimates the wrapped centre phase of a processing block, with spread estimation, which estimates the signed intra-block phase evolution. Phase unwrapping and section-based phase compensation then convert these estimates into per-section correction phases for the delayed received symbol block.

The implemented \ac{RTL} uses packed Q1.15 I/Q samples, trigonometric phase coefficients in the \ac{SBPS} path and Q4.28 phase words in the spread-estimation, unwrapping and compensation paths. The spread-estimation branch includes candidate-symbol selection, fourth-power processing, normalized dot-product evaluation, sign estimation, filtering and \ac{LUT}-based angle recovery. A top-level wrapper aligns the \ac{SBPS} centre-phase estimate, the signed spread estimate and the delayed raw I/Q block before final compensation.

The design is verified using Python reference models, generated fixed-point vectors, \ac{VHDL} testbenches and post-processing scripts. Top-level simulations show no persistent phase drift between the Python model and the \ac{RTL}; the largest measured mean model difference over the evaluated cases is 2.251 mrad. For the default residual-\ac{CFO} test case, the impaired signal has an \ac{EVM} of 142\%. Blockwise \ac{SBPS} correction reduces this to 12.69\%, while combined \ac{SBPS} and spread-estimation compensation reduces it further to 7.41\%. Implementation on an XCU200 target shows that the evaluated \(B=32\), six-stage, eight-section configuration uses about \(33.3\mathrm{k}\) LUTs, \(36.0\mathrm{k}\) flip-flops, 229 DSP blocks and four BRAM tiles, and closes timing at an \(8~\mathrm{ns}\) clock period after a local pipeline register is added in the spread-estimation path.
